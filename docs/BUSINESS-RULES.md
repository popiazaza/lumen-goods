# Business rules

The rules Lumen Goods enforces to meet the spec's business, payment and wallet requirements, and the scenarios that prove each one.
Each rule lives in one place in code (a policy or service whose comment carries the ID). Its tests are named and tagged with the ID, `BR_PAY_01_...` + `[Trait("BR", "BR-PAY-01")]`, so `dotnet test --filter-trait "BR=BR-PAY-01"` runs one rule's tests.
**Tests column:** the main test classes for each rule (unit, including CsCheck property tests over random carts; integration = the real API on PostgreSQL via Testcontainers; end-to-end = a running stack over HTTP only; `.spec.ts` = Angular, or under `src/web/e2e` a Playwright browser test against the running stack). The filter above runs every test of a rule.
Example amounts use the configured defaults: EUR→USD 1.0850, sales tax 8 %, Standard shipping $4.99, Express $12.99, price hold 15 min.
